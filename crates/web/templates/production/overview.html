Invarian yang dijaga

①

Single-Tag AEAD

Seluruh pesan menghasilkan tepat satu tag autentikasi; komputasi paralel menghasilkan output byte-identik dengan standar RFC 8452.

②

Verifikasi Tanpa Kebocoran

Verifikasi tag dilakukan secara constant-time; zero plaintext release sebelum validasi tag sukses.

③

Perlindungan PII Enkripsi Kolom

Data pribadi (Email, NIK) tersimpan terenkripsi AES-256-GCM-SIV dengan AAD terikat baris di MariaDB.

④

Ketahanan HTTP & Sesi

Strict CSP tanpa inline scripts/styles, TLS 1.3 only, HSTS 1 tahun, dan cookie sesi HttpOnly SameSite=Strict.
